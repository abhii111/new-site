# India's Seven Wonders Website

A beautiful, responsive website showcasing India's Seven Wonders with detailed information, addresses, and historical facts about each monument.

## 🏛️ Featured Wonders

1. **Taj Mahal** - Agra, Uttar Pradesh
   - A symbol of love and Mughal architecture at its finest
   
2. **Hawa Mahal** - Jaipur, Rajasthan
   - The iconic pink Palace of Winds with 953 intricate windows
   
3. **Ajanta Caves** - Aurangabad, Maharashtra
   - 30 Buddhist monastery caves with exquisite artwork and murals
   
4. **Ellora Caves** - Aurangabad, Maharashtra
   - 34 multi-faith caves showcasing Hindu, Buddhist, and Jain architecture
   
5. **Khajuraho Temples** - Madhya Pradesh
   - 22 temples famous for intricate erotic sculptures and craftsmanship
   
6. **Statue of Unity** - Kevadia, Gujarat
   - World's tallest statue honoring Sardar Vallabhbhai Patel (182 meters)
   
7. **Gateway of India** - Mumbai, Maharashtra
   - Iconic Indo-Saracenic monument and symbol of Mumbai

## 📋 Features

- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **Detailed Information**: Complete information including location, address, history, and significance
- **Image Gallery**: Visual representation of each wonder
- **Modern UI**: Clean and intuitive interface with smooth animations
- **Navigation**: Easy-to-use navigation with sections for Home, Wonders, and About
- **Tags & Highlights**: Quick info tags for each monument

## 🚀 Getting Started

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- Internet connection (for downloading images)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/abhii111/new-site.git
   cd new-site
   ```

2. Open the website:
   ```bash
   # Simply open index.html in your browser
   ```

3. Or use a local server:
   ```bash
   # Using Python 3
   python -m http.server 8000
   
   # Using Node.js http-server
   npx http-server
   ```

## ✨ Customization

- Images: Replace with your own wonder photos
- Layout: Adjust grid and spacing in styles.css
